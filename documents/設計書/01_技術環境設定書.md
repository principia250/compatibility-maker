# 技術環境設定書

## 1. プロジェクト概要

### 1.1 技術スタック

- **フロントエンド**: Next.js 14 (App Router)
- **バックエンド**: Next.js API Routes
- **データベース**: Supabase (PostgreSQL)
- **認証**: Supabase Auth
- **ホスティング**: Vercel
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Context + useState
- **フォーム**: React Hook Form + Zod
- **国際化**: 条件式による文言の出しわけ（英語・日本語）

### 1.2 開発環境

- **Node.js**: 18.17.0以上
- **npm**: 9.0.0以上
- **Git**: 2.30.0以上

## 2. プロジェクト初期化手順

### 2.1 Next.jsプロジェクトの作成

```bash
# プロジェクト作成
npx create-next-app@latest compatibility-maker --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"

# プロジェクトディレクトリに移動
cd compatibility-maker

# 依存関係のインストール
npm install
```

### 2.2 必要なパッケージのインストール

```bash
# Supabase関連
npm install @supabase/supabase-js @supabase/auth-helpers-nextjs

# フォーム関連
npm install react-hook-form @hookform/resolvers zod

# UI関連
npm install @radix-ui/react-slot
npm install lucide-react

# 国際化
条件式による文言の出しわけで英語・日本語に対応
- 言語切り替えはuseStateで管理
- 翻訳データはオブジェクト形式で管理
- ライブラリは使用しない

# 日付処理
npm install date-fns

# バリデーション
npm install class-validator class-transformer

# 開発用ツール
npm install -D @types/node
```

### 2.3 環境変数の設定

`.env.local`ファイルを作成し、以下の環境変数を設定：

```env
# Supabase設定
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# アプリ設定
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME=Compatibility Maker

# 開発環境設定
NODE_ENV=development
```

## 3. Supabaseプロジェクトの設定

### 3.1 Supabaseプロジェクトの作成

1. [Supabase](https://supabase.com)にアクセス
2. 新しいプロジェクトを作成
3. プロジェクト名: `compatibility-maker`
4. データベースパスワードを設定
5. リージョンを選択（東京リージョン推奨）

### 3.2 環境変数の取得

1. プロジェクト設定 → API
2. Project URL をコピー → `NEXT_PUBLIC_SUPABASE_URL`
3. anon public キーをコピー → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. service_role キーをコピー → `SUPABASE_SERVICE_ROLE_KEY`

### 3.3 データベース設定

1. SQL Editorで初期テーブルを作成
2. RLS (Row Level Security) の設定
3. 認証設定の確認

## 5. プロジェクト構造

### 5.1 ディレクトリ構成

```
src/
├── app/                    # Next.js App Router
│   ├── (auth)/            # 認証関連ページ
│   ├── api/               # API Routes
│   ├── charts/            # 相性図関連ページ
│   ├── dashboard/         # ダッシュボード
│   └── globals.css        # グローバルスタイル
├── components/             # 再利用可能コンポーネント
│   ├── ui/                # 基本UIコンポーネント
│   ├── forms/             # フォーム関連コンポーネント
│   └── charts/            # 相性図関連コンポーネント
├── lib/                    # ユーティリティ関数
│   ├── supabase/          # Supabase関連
│   ├── utils/             # 汎用ユーティリティ
│   └── validations/       # バリデーションスキーマ
├── types/                  # TypeScript型定義
└── hooks/                  # カスタムフック
```

### 5.2 ファイル命名規則

- **コンポーネント**: PascalCase (例: `ChartEditor.tsx`)
- **ページ**: kebab-case (例: `chart-detail.tsx`)
- **API Routes**: kebab-case (例: `create-chart.ts`)
- **ユーティリティ**: camelCase (例: `formatDate.ts`)
- **型定義**: PascalCase (例: `Chart.ts`)

# 単体テスト設計書

## 1. テスト概要

### 1.1 テスト方針

- **段階的なテスト導入**: 学習しながら徐々にテストを充実
- **実用的なテスト**: 完璧を求めず、バグの早期発見を重視
- **学習重視**: テストの書き方を理解しながら実装
- **手動実行**: CI/CDは見送り、手動でテスト実行

### 1.2 テスト対象

- **フロントエンド**: React コンポーネント、カスタムフック、ユーティリティ関数
- **バックエンド**: API Routes、データベース操作、バリデーション関数
- **共通**: 型定義、設定ファイル、エラーハンドリング

### 1.3 テストツール

- **Jest**: テストランナー（Next.js標準）
- **React Testing Library**: コンポーネントテスト
- **MSW**: APIモック（外部依存を避ける）
- **@testing-library/jest-dom**: DOM要素のテスト用マッチャー

### 4.4 API呼び出しのテスト

```typescript
// API呼び出しのテスト例
// src/lib/api/charts.test.ts
import { fetchCharts } from './charts';
import { server } from '../../mocks/server';
import { rest } from 'msw';

describe('fetchCharts', () => {
  it('相性図一覧を正しく取得する', async () => {
    const mockCharts = [
      { id: '1', title: 'テスト相性図1' },
      { id: '2', title: 'テスト相性図2' },
    ];

    server.use(
      rest.get('/api/charts', (req, res, ctx) => {
        return res(ctx.json({ success: true, data: { charts: mockCharts } }));
      })
    );

    const result = await fetchCharts();
    expect(result.charts).toHaveLength(2);
    expect(result.charts[0].title).toBe('テスト相性図1');
  });

  it('エラー時に適切にハンドリングする', async () => {
    server.use(
      rest.get('/api/charts', (req, res, ctx) => {
        return res(
          ctx.status(500),
          ctx.json({ success: false, error: 'サーバーエラー' })
        );
      })
    );

    await expect(fetchCharts()).rejects.toThrow('サーバーエラー');
  });
});
```
